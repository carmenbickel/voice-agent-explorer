# Returns

## Eligibility

Unworn shoes can be returned within 30 days of delivery with the original box.
Demo note: exact terms are draft demo data for this showcase.

## How returns are processed

Ask the assistant for a return of a specific order line. Refunds are simulated
in this demo; the local reference given by the assistant is the demo-only
record.
